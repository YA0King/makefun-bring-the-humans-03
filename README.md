The video: https://www.tiktok.com/@xv_8796/video/7711582949967203597

The program `main.ts` copies `VIDEO.json` from the repository root to `/output/VIDEO.json`; that is all it has to do. The house reads the video itself from TikTok and ranks the entry by its views.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
